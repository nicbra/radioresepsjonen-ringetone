# Radioresepsjonen ringetone

Dette python-skriptet vil lage en ringetone tilsvarende ringetonen du hører i Radioresepsjonen i innslagene hvor noen ringer inn.

Det er en tre-toners ringelyd på 
- 804 Hz
- 1075 Hz
- 1343 Hz

Hver på 50 ms, repetert 7 ganger.

Til slutt er det en 2 sekunders stillhet så du kan bruke det som en ringetone.

## Avhengigheter
```
pip3 install numpy wave
```
